# NEC765 FDC + `.dsk` floppy support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `Model::Spectrum2A3` a real, working NEC765/uPD765A floppy
disk controller (read-only command set, instant-transfer Execution
phase) that can load real sector data off a standard CPCEMU `.dsk` image
through the real port protocol (`0x2ffd`/`0x3ffd`).

**Architecture:** Two new zero-path-dep crates -- `crates/nec765` (chip
protocol: phase state machine, MSR bits, the 6 read-only commands) and
`crates/dsk` (parses a `.dsk` byte buffer into a plain `Disk` struct) --
meet only inside `zx-spectrum`'s own bus wiring, via a local `DiskMedium`
newtype that implements `nec765`'s trait for a wrapped `dsk::Disk`
(neither format crate depends on the other, or on `nec765`/`dsk`
depending on each other -- same decoupling precedent as every other
format crate in this codebase, see `CLAUDE.md`).

**Tech Stack:** Rust (edition 2024), no new external dependencies.

**Spec:** `docs/superpowers/specs/2026-09-11-nec765-fdc-design.md`

## Global Constraints

- New crates (`nec765`, `dsk`) have **zero path dependencies** -- same
  "peer format/chip crate" precedent as `ay-3-8910`/`zx-tape`/
  `z80-snapshot`. Neither depends on the other; both are wired together
  only inside `zx-spectrum`'s own `bus.rs`.
- Read-only command set only: Specify (`0x03`), Recalibrate (`0x07`),
  Seek (`0x0F`), Sense Interrupt Status (`0x08`), Read Data (`0x06`),
  Read ID (`0x0A`). Any other command byte -> a 1-byte invalid-command
  result (`0x80`), not a panic.
- Execution phase is instant (same tick) -- no real seek/rotational
  timing. `Fdc<D>` is generic over `D: DiskMedium`, not a trait object.
- `0x2ffd`/`0x3ffd` port decode (`port & 0xF002 == 0x2000` /
  `== 0x3000`) is an **assumed** pattern (by analogy with `0x1ffd`'s
  verified `0xF002` family), not independently verified against the +3
  manual -- every doc comment that states it must say so explicitly, per
  this codebase's existing epistemic-honesty convention (see `CLAUDE.md`).
- Real command/result byte counts and field meanings ARE verified
  against the actual uPD765 datasheet (fetched during spec-writing, see
  `CREDITS.md` once Task 10 adds the entry) -- keep doc comments citing
  that, not recollection.
- `cargo fmt`, `cargo clippy -- -D warnings`, and the full
  `cargo test --workspace` must stay clean after every task's commit.
- Follow this codebase's comment convention throughout: no comments
  explaining *what* code does: only non-obvious *why* (a hidden
  constraint, a cited real-hardware fact, a scope decision).

//! NEC765/uPD765A floppy disk controller emulation -- the ZX Spectrum
//! +3's real FDC. Protocol-only: no dependency on any disk file format
//! (see `DiskMedium` below) or any host machine crate, same reasoning as
//! `crates/ay-3-8910` (a real chip's own documented protocol, usable by
//! any host that wires up the right ports). Command-phase/result-phase
//! byte counts and field meanings verified against the real uPD765
//! datasheet (see `CREDITS.md`), not recollection.
//!
//! Approved scope (see `docs/superpowers/specs/2026-09-11-nec765-fdc-
//! design.md`): read-only commands, instant Execution phase -- no real
//! seek/rotational timing modeled.

/// One sector's real NEC765 ID field. `size_code` is the chip's own
/// `128 << size_code` sector-size encoding -- matches the `.dsk` file
/// format's own per-sector size byte 1:1, so no conversion is needed
/// either direction (see `dsk::Sector`).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SectorId {
    pub cylinder: u8,
    pub head: u8,
    pub sector: u8,
    pub size_code: u8,
}

/// What the chip needs from a disk to serve Read Data/Read ID -- this
/// crate has no idea `.dsk` (or any other disk file format) exists;
/// implemented for a real parsed disk in `zx-spectrum`'s own bus wiring.
pub trait DiskMedium {
    /// The first sector this medium has for `(cylinder, head)` -- Read
    /// ID's real semantics: no rotational position tracked, so this
    /// always returns whichever sector happens to be first in the
    /// medium's own sector list for that track.
    fn first_sector(&self, cylinder: u8, head: u8) -> Option<(SectorId, &[u8])>;
    /// One specific sector by its real ID fields -- Read Data's own
    /// params name exactly these.
    fn read_sector(&self, cylinder: u8, head: u8, sector: u8) -> Option<(SectorId, &[u8])>;
}

const RQM: u8 = 0x80;
const DIO: u8 = 0x40;

enum Phase {
    Idle,
    Command {
        opcode: u8,
        params_needed: usize,
        params: Vec<u8>,
    },
    Result {
        bytes: Vec<u8>,
        pos: usize,
    },
}

/// Number of parameter bytes the command phase needs to see before
/// `Fdc` can execute it, per the real uPD765 datasheet's command-phase
/// byte tables. Any opcode not listed here is treated as unrecognized:
/// 0 further param bytes expected, straight to an invalid-command result
/// (see `Fdc::write_data`'s doc comment) -- not a guess at how many
/// bytes a totally unknown command would really take.
fn param_count(opcode: u8) -> usize {
    match opcode {
        0x03 => 2, // Specify: SRT/HLT, HUT/ND
        0x07 => 1, // Recalibrate: US1/US0
        0x0F => 2, // Seek: HD/US1/US0, NCN
        0x08 => 0, // Sense Interrupt Status
        0x06 => 8, // Read Data: HD/US1/US0, C, H, R, N, EOT, GPL, DTL
        0x0A => 1, // Read ID: HD/US1/US0
        _ => 0,
    }
}

/// The NEC765/uPD765A itself. Generic over `D: DiskMedium` rather than a
/// trait object -- one concrete disk type per real machine instance, no
/// need for dynamic dispatch, and this crate's own tests can use a
/// trivial in-memory fake without depending on `dsk`.
pub struct Fdc<D: DiskMedium> {
    disk: Option<D>,
    /// Real cylinder register the head is "positioned" over -- Seek/
    /// Recalibrate set it instantly (no real seek time modeled, per
    /// approved scope); Sense Interrupt Status reads it back as PCN.
    cylinder: u8,
    phase: Phase,
}

impl<D: DiskMedium> Default for Fdc<D> {
    fn default() -> Self {
        Self::new()
    }
}

impl<D: DiskMedium> Fdc<D> {
    pub fn new() -> Self {
        Self {
            disk: None,
            cylinder: 0,
            phase: Phase::Idle,
        }
    }

    /// Replaces any disk already inserted -- a real drive can only hold
    /// one at a time.
    pub fn insert_disk(&mut self, disk: D) {
        self.disk = Some(disk);
    }

    /// Port `0x2ffd`, read-only (port decode is an assumed pattern, see
    /// `zx_spectrum::bus`'s own doc comment where this is wired up --
    /// not independently verified here). Bit 7 (RQM) is always set:
    /// Execution is instant (approved scope), so there's never a phase
    /// where the chip is busy and can't accept/give the next byte. Bit 6
    /// (DIO) is set only during a Result phase (chip-to-host); clear
    /// during Idle or Command phase (host-to-chip).
    pub fn read_msr(&self) -> u8 {
        let dio = matches!(self.phase, Phase::Result { .. });
        RQM | if dio { DIO } else { 0 }
    }

    /// Port `0x3ffd` read (Result phase, chip-to-host). Returns `0xFF`
    /// if called outside a Result phase -- the datasheet leaves this
    /// case undefined (the host is expected to check MSR first); this
    /// project returns an idle-bus value rather than panicking.
    pub fn read_data(&mut self) -> u8 {
        match &mut self.phase {
            Phase::Result { bytes, pos } => {
                let byte = bytes.get(*pos).copied().unwrap_or(0);
                *pos += 1;
                if *pos >= bytes.len() {
                    self.phase = Phase::Idle;
                }
                byte
            }
            _ => 0xFF,
        }
    }

    /// Port `0x3ffd` write (Command phase, host-to-chip). The command
    /// byte itself only arrives while Idle; every following byte until
    /// `param_count(opcode)` have been seen is a parameter. Execution is
    /// instant (approved scope): the moment the last parameter byte
    /// lands, `execute` runs immediately, in this same call.
    pub fn write_data(&mut self, val: u8) {
        match &mut self.phase {
            Phase::Idle => {
                let needed = param_count(val);
                if needed == 0 {
                    self.execute(val, &[]);
                } else {
                    self.phase = Phase::Command {
                        opcode: val,
                        params_needed: needed,
                        params: Vec::new(),
                    };
                }
            }
            Phase::Command {
                opcode,
                params_needed,
                params,
            } => {
                params.push(val);
                if params.len() == *params_needed {
                    let opcode = *opcode;
                    let params = std::mem::take(params);
                    self.execute(opcode, &params);
                }
            }
            // Real hardware ignores a write outside Command phase (the
            // host is expected to check MSR first) -- same "undefined by
            // the datasheet, don't panic" stance as `read_data`.
            Phase::Result { .. } => {}
        }
    }

    fn execute(&mut self, opcode: u8, _params: &[u8]) {
        let result: Vec<u8> = match opcode {
            _ => vec![0x80], // invalid command -- real commands added in Tasks 2-5.
        };
        self.phase = if result.is_empty() {
            Phase::Idle
        } else {
            Phase::Result {
                bytes: result,
                pos: 0,
            }
        };
    }
}

    /// hardware can chain through `EOT` (params[5]) to read several
    /// consecutive sectors in one command; this project's approved scope
    /// accepts `EOT`/`GPL`/`DTL` as real params but doesn't use them to
    /// extend the transfer past that one sector (see the design spec's

    /// hardware-verified claim about real EOT chaining).

        let head = params[2]; // H
        let sector = params[3]; // R
        let found = self.disk.as_ref().and_then(|d| d.read_sector(cylinder, head, sector));

            // Read ID's own no-disk case.
            None => vec![0x40, 0x00, 0x00, cylinder, head, sector, params[4]],

//! Parses a standard CPCEMU `.dsk` disk image -- the format the ZX
//! Spectrum +3 (and the Amstrad CPC, which originated it) both use. No
//! dependency on `machine`, any CPU crate, or `nec765` -- same "format
//! crate only parses bytes into a plain struct" precedent as
//! `z80-snapshot`/`zx81-snapshot`/`zx-tape`. Byte layout verified against
//! cpctech.cpcwiki.de's own DSK format reference (see `CREDITS.md`), not
//! recollection.
//!
//! Extended DSK (a different signature, variable-size tracks) is a clear
//! parse error here, not silently misread -- standard DSK only (approved
//! scope, see `docs/superpowers/specs/2026-09-11-nec765-fdc-design.md`).

const DISC_SIGNATURE: &[u8] = b"MV - CPCEMU Disk-File\r\nDisk-Info\r\n";
const TRACK_SIGNATURE: &[u8] = b"Track-Info\r\n";
const BLOCK_SIZE: usize = 0x100;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Error {
    TooShort,
    NotAStandardDskFile,
    TruncatedTrack(usize),
}

impl std::fmt::Display for Error {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Error::TooShort => write!(f, "file shorter than the 256-byte Disc Information block"),
            Error::NotAStandardDskFile => write!(
                f,
                "not a standard CPCEMU .dsk file (missing 'MV - CPCEMU...' signature -- Extended DSK isn't supported)"
            ),
            Error::TruncatedTrack(index) => write!(f, "track {index} truncated -- file ends mid-track"),
        }
    }
}

impl std::error::Error for Error {}

/// One sector's real ID fields plus its raw data. `size_code` is the
/// NEC765 N encoding (`128 << size_code` bytes) -- the file's own sector-
/// info byte, unconverted (see `nec765::SectorId`'s doc comment for why
/// the two crates share this exact encoding without knowing about each
/// other).
#[derive(Debug, Clone)]
pub struct Sector {
    pub cylinder: u8,
    pub head: u8,
    pub sector: u8,
    pub size_code: u8,
    pub data: Vec<u8>,
}

#[derive(Debug, Clone, Default)]
struct Track {
    sectors: Vec<Sector>,
}

/// A parsed standard CPCEMU `.dsk` image.
#[derive(Debug, Clone)]
pub struct Disk {
    tracks: Vec<Track>,
    heads: u8,
}

impl Disk {
    /// The first sector this disk has for `(cylinder, head)`, in the
    /// file's own sector-info table order.
    pub fn first_sector(&self, cylinder: u8, head: u8) -> Option<&Sector> {
        self.track(cylinder, head)?.sectors.first()
    }

    /// One specific sector by its real ID fields.
    pub fn read_sector(&self, cylinder: u8, head: u8, sector: u8) -> Option<&Sector> {
        self.track(cylinder, head)?.sectors.iter().find(|s| s.sector == sector)
    }

    fn track(&self, cylinder: u8, head: u8) -> Option<&Track> {
        let index = cylinder as usize * self.heads as usize + head as usize;
        self.tracks.get(index)
    }
}

pub fn parse(bytes: &[u8]) -> Result<Disk, Error> {
    if bytes.len() < BLOCK_SIZE {
        return Err(Error::TooShort);
    }
    if &bytes[..DISC_SIGNATURE.len()] != DISC_SIGNATURE {
        return Err(Error::NotAStandardDskFile);
    }

    let track_count = bytes[0x30] as usize;
    let head_count = bytes[0x31];
    // Includes the 0x100-byte Track Information block itself, per the
    // format reference -- the next track starts exactly `track_size`
    // bytes after this one, not `BLOCK_SIZE` + a separately-tracked data
    // length.
    let track_size = u16::from_le_bytes([bytes[0x32], bytes[0x33]]) as usize;

    let mut tracks = Vec::with_capacity(track_count * head_count as usize);
    let mut offset = BLOCK_SIZE;
    for index in 0..(track_count * head_count as usize) {
        let block = bytes
            .get(offset..offset + BLOCK_SIZE)
            .ok_or(Error::TruncatedTrack(index))?;
        if &block[..TRACK_SIGNATURE.len()] != TRACK_SIGNATURE {
            return Err(Error::TruncatedTrack(index));
        }
        let sector_count = block[0x15] as usize;

        let mut sectors = Vec::with_capacity(sector_count);
        let mut data_offset = offset + BLOCK_SIZE;
        for s in 0..sector_count {
            let entry = &block[0x18 + s * 8..0x18 + s * 8 + 8];
            let size_code = entry[3];
            let size = 128usize << size_code;
            let data = bytes
                .get(data_offset..data_offset + size)
                .ok_or(Error::TruncatedTrack(index))?
                .to_vec();
            sectors.push(Sector {
                cylinder: entry[0],
                head: entry[1],
                sector: entry[2],
                size_code,
                data,
            });
            data_offset += size;
        }

        tracks.push(Track { sectors });
        offset += track_size;
    }

    Ok(Disk {
        tracks,
        heads: head_count,
    })
}

    /// Parses `bytes` as a `.dsk` disk image and installs it -- same
    /// "concrete per-machine dispatch" reasoning as `apply_snapshot`/
    /// `apply_tape`. Rejects `AnyMachine::Zx81` outright (no FDC concept
    /// at all there); `ZxSpectrum::load_disk` itself rejects any
    /// Spectrum model other than `Model::Spectrum2A3`.
    pub fn apply_disk(&mut self, extension: &str, bytes: &[u8]) -> Result<(), String> {
        match self {
            AnyMachine::Zx81(_) => Err("--disk isn't supported for --machine zx81".to_string()),
            AnyMachine::ZxSpectrum(m) => match extension {
                "dsk" => {
                    let disk = dsk::parse(bytes).map_err(|e| e.to_string())?;
                    m.load_disk(disk)
                }
                other => Err(format!(
                    "--disk: unsupported extension \".{other}\" (expected .dsk)"
                )),
            },
        }
    }
