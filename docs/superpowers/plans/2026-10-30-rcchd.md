# rcchd: CHD tool (chdman's job) Implementation Plan

**Goal:** `rcchd` in retroclawd-tools creates, extracts, inspects, verifies and edits CHD v5 files (CD, GD-ROM, DVD, hard disk, raw),
the way `rcdisk` and `rctape` do for disks and tapes.

**Architecture:** the `chd` crate of the Sega family (a format crate: `forbid(unsafe_code)`, untrusted input) grows from a CD-only reader into a
generic CHD library: a hunk codec layer (zlib, zstd, lzma, huff, flac, cdzl, cdzs, cdlz, cdfl), a generic reader (`Image`, parent files), and a
writer (compressed map, metadata chain, SHA-1s). `rcchd` (tools repository) holds the command line and the media conversions (cue/bin, iso,
gdi, toc to and from frames; hard-disk geometry; DVD and raw images) and depends on `chd` by git revision.

**Reference:** chdman 0.28x (`C:\Users\matti\Workspace\Emulators\Mame\chdman.exe`) is a black box oracle: what we write it verifies, what it
writes we verify. MAME's `chd.h`, `chdcodec.cpp`, `huffman.cpp` are read for understanding only (clean room: no code, tables or comments copied).

**Commands (chdman's names):** info, verify, createraw, createhd, createcd, createdvd, extractraw, extracthd, extractcd, extractdvd, addmeta,
delmeta, dumpmeta, copy, listtemplates. Not done: createld/extractld (laser-disc video, `avhu` codec: needs AVI video input) and CHD versions 1-4.

## Global constraints

- Reader: every size read from a file is bounded before memory is reserved; a damaged file is an error, never a panic.
- Machine/chip/format crates keep `#![forbid(unsafe_code)]`; dependencies: pure Rust only.
- Nothing downloaded or produced is committed (ROMs, discs, CHDs). Test discs are synthetic.
- Output files are never overwritten unasked (`--force`).

## Milestones (each ends with a commit and green `cargo test` and clippy)

**Status 2026-10-30: all seven are done**, except `.toc` input (not done; chdman's `.nrg`, WAV and MP3 inputs neither). Real-file proof: the 111 MB Mad Dog McCree CHD from RomM verifies (6 s), extracts to cue/bin and is made again by `rcchd createcd` with the same data and overall SHA-1 as the original.

1. **Codecs** (done): generic codec layer both ways; unit round trips; cross check: chdman verifies our hunks and we read chdman's.
2. **Writer**: header, compressed and uncompressed map, metadata with SHA-1s, self and parent hunks. Proof: `chdman verify` accepts our files, `chdman info` shows the same SHA-1s.
3. **Generic reader** (`Image`) and the CD view (`Chd`) on top of it; all existing tests unchanged.
4. **rcchd CD**: createcd (cue/bin, iso, gdi, toc), extractcd (cue/bin, split bin), info, verify. Proof: round trip with chdman both ways, real Mad Dog McCree.
5. **rcchd generic**: createraw/hd/dvd, extractraw/hd/dvd, copy, addmeta/delmeta/dumpmeta, listtemplates, parents.
6. **GD-ROM**: CHGD/CHGT metadata, gdi in and out.
7. Docs (`docs/rcchd.md`, both CLAUDE.md files, README, TODO), pin bumps, `check_all`.
