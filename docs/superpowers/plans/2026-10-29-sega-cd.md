# Sega CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) syntax.

**Goal:** a `segacd` machine in `retroclawd-sega` that boots a Sega CD BIOS and runs the 29 RomM games.

**Architecture:** new family crates (`disc`, `rf5c164`, `lc89510`, `mcd-gate-array`, `mcd-asic`, `segacd`) on top of the Genesis crates; the disc reaches the plugin by path (no ABI change); a second shared `mc68000` is the sub-CPU.

**Tech Stack:** Rust 2024, `mc68000`/`z80`/`machine`/`plugin-api` from `retroclawd-crates`, `rc-scenarios` and the libretro oracle host from `retroclawd-tools`.

**Spec:** `docs/superpowers/specs/2026-10-29-sega-cd-design.md`

## Global Constraints

- Clean-room: no source, table, constant or comment copied from a reference emulator; every hardware fact has a row in `machines/sega/docs/hardware-facts.md` labelled `[D]/[H]/[O]/[H?]` before it is coded; an unknown I/O address stops the machine.
- `#![forbid(unsafe_code)]` in every machine/chip/format crate; machine time only from the scheduler (no wall clock, no floats in timing).
- Never commit ROMs, discs, BIOS files, goldens, datasheets, oracle cores. Downloaded files are untrusted: own directory, `python -I`.
- Untrusted input never panics: cue sheets, images (and later CHD) return errors.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; explicit `git add` paths; `git checkout Cargo.lock` in `machines/sega` before pushing; ask before pushing.
- `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt`, `cargo test` clean per task.

## Review Focus

- A cue sheet naming `../../etc/x`, an absolute path, or a missing BIN: refused with an error naming the line/file.
- A BIN whose size is not a multiple of the sector size, or shorter than the cue implies: error or clamped, never a panic or a read past the end.
- Read of an LBA outside the disc, in a pregap, or in lead-out: defined result (error / zeros), never a panic.
- Multi-BIN cue (one file per track) and single-BIN cue give identical TOCs for the same content.
- Huge or hostile cue (100000 lines, 1000 tracks, binary garbage): bounded work, error.

## Slice 1: disc crate (detailed; slices 2-9 get their own plan files when their facts are sourced)

Slices 2-9 of the spec (sub-CPU system, CDD/CDC, peripherals, audio, games, ASIC, FMV, CHD) each need hardware facts sourced first (spec section 4), so each is planned in its own `docs/superpowers/plans/2026-..-sega-cd-sliceN.md` when it starts. The host routing (`--disc`, zip/URL extraction of every entry, `load_disc` action) is part of slice 2, where a machine exists to receive it.

### Task 1: cue sheet parser

**Files:** Create `machines/sega/crates/formats/disc/{Cargo.toml,src/lib.rs,src/cue.rs}`; Modify `machines/sega/Cargo.toml` (member).

**Interfaces:**
- Produces: `cue::parse(text: &str) -> Result<CueSheet, DiscError>`; `CueSheet { files: Vec<CueFile> }`, `CueFile { name: String, tracks: Vec<CueTrack> }`, `CueTrack { number: u8, kind: TrackKind, pregap: u32, postgap: u32, indexes: Vec<(u8, u32)> }` (index positions in sectors from the start of the file), `TrackKind { Audio, Mode1Raw, Mode1Cooked, Mode2Raw, Mode2Cooked }` (`sector_size()` 2352/2048), `DiscError` (Display, `PartialEq`).

- [ ] Tests (`cue::tests`): `parses_a_single_bin_cue` (FILE/TRACK 01 MODE1/2352/INDEX 01 00:00:00, TRACK 02 AUDIO/INDEX 00 + 01), `parses_one_bin_per_track`, `msf_converts_to_sectors` (`00:02:00` = 150, `74:59:74` = 337 499), `rejects_bad_msf` (`00:60:00`, `00:00:75`, `aa:bb:cc`), `rejects_path_escape` (`../x.bin`, `/abs.bin`, `C:\x.bin`, `a/../../b.bin`), `rejects_unknown_mode`, `rejects_track_before_file`, `bounds_hostile_input` (200 000 lines and 1000 tracks give an error; binary garbage gives an error), `accepts_quotes_rem_lines_and_crlf`.
- [ ] Run: `cargo test -p disc` — Expected: FAIL (crate missing), then PASS after the implementation.
- [ ] Implement per signatures; limits: 99 tracks (CD limit), 100 files, 64 KiB of text.
- [ ] Commit `git add machines/sega/crates/formats/disc machines/sega/Cargo.toml` — "disc: cue sheet parser".

### Task 2: disc images and sector reads

**Files:** Create `src/disc.rs`, `src/iso.rs` (or inside `disc.rs`); Test: `crates/formats/disc/tests/images.rs` (builds images in a temp dir).

**Interfaces:**
- Consumes: Task 1.
- Produces: `Disc::open(path: &Path) -> Result<Disc, DiscError>` (`.cue`, `.iso`; `.chd` gives `DiscError::Unsupported("chd")` until slice 9); `Disc::tracks(&self) -> &[Track]`; `Track { number: u8, kind: TrackKind, start_lba: u32 /* index 01 */, pregap_lba: u32 /* index 00 or start */, sectors: u32 }`; `Disc::lead_out(&self) -> u32` (LBA, 150-sector lead-in offset NOT included: LBA 0 = MSF 00:02:00); `Disc::read_raw(&mut self, lba: u32, out: &mut [u8; 2352]) -> Result<(), DiscError>` (cooked sources are expanded: 12-byte sync, MSF header, mode byte, user data, zeroed EDC/ECC, documented); `Disc::read_user(&mut self, lba: u32, out: &mut [u8; 2048])` (mode 1 only); `Disc::msf(lba) -> (u8,u8,u8)`.

- [ ] Tests: `single_bin_and_split_bins_give_the_same_toc`, `cooked_iso_expands_to_a_valid_raw_sector` (sync pattern, header MSF, mode 1, data intact), `reads_audio_sectors_verbatim`, `read_outside_the_disc_is_an_error`, `pregap_reads_are_zeros_or_file_data_as_the_cue_says`, `bin_not_a_multiple_of_the_sector_size_is_an_error`, `missing_bin_names_the_file`, `a_bin_shorter_than_the_cue_implies_is_clamped_not_panicking`, `cue_paths_stay_inside_the_cue_folder` (symlink-free check by path components).
- [ ] Run `cargo test -p disc` — Expected: FAIL then PASS.
- [ ] Implement: lazy `File` per BIN, `seek` + `read_exact`, one-sector cache, track table built from indexes (index 01 starts the track; index 00 or PREGAP gives pregap; a `PREGAP` with no file data is silent zeros).
